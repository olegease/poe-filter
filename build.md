# BUILD
> each class are restricted to use Strength, Dexterity, and Intelligence required items according to a scheme below

No mapping (atlas content) allowed, only campaign and accessible through campaign extra content!!!

## Utility Tags
> Utility is a gem that at least contains one of this tags:

- `Aura`
- `Blink`
- `Brand`
- `Curse`
- `Guard`
- `Herald`
- `Hex`
- `Link`
- `Mark`
- `Mine`
- `Minion`
- `Movement`
- `Retaliation`
- `Stance`
- `Totem`
- `Trap`
- `Travel`
- `Trigger`
- `Warcry`
